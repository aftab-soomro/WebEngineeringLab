Where I almost used a <div>, and what I used instead

While rewriting the blog markup I almost wrapped the whole post in <div class="post">, but I used <article> instead, because the post is self-contained and still makes sense if you lift it out of the page.

<div class="top"> became a <header> holding an <h1> and a <nav>, so a screen reader can announce the page title and jump straight to the navigation landmark.

Instead of <div class="date"> I used <time datetime="2026-08-09"> so the date is machine-readable, and <span onclick="go('/')"> became a real <a href> that works with the keyboard.

On the contact page I almost used <div>s to push the fields apart, but I wrapped each label and input in a <p> and left the real spacing for CSS in Week 03.

The only place I would still reach for a <div> is a pure styling wrapper that carries no meaning of its own.
